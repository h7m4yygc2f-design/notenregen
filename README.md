# Notenregen

Piano-oefenapp met vallende noten. Laad een partituur (MusicXML, MIDI of zelf getypt) en speel mee.
Met de microfoonknop luistert de app naar je echte piano: bij "Wachten op mij" gaat het liedje pas verder als hij de juiste noot hoort.

Open de app: https://h7m4yygc2f-design.github.io/notenregen/

Pianogeluid: Salamander Grand Piano V3, opgenomen door Alexander Holm (CC BY 3.0).
